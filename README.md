# Fala

Ditado por voz leve para Windows: segure o atalho, fale, e o texto limpo aparece onde está o cursor.

Este repositório guarda apenas os instaladores. Baixe a versão mais recente em **Releases**.

## Instalar

1. Baixe o arquivo `Fala-Setup-<versão>.exe` da versão mais recente.
2. Abra o arquivo. O instalador não é assinado, então o Windows mostra "editor desconhecido": clique em "Mais informações" e depois em "Executar assim mesmo".
3. Abra o Fala (um círculo aparece na bandeja do Windows) e, nas configurações, preencha:
   - a **chave de licença** que você recebeu (uma chave vale para um computador);
   - a sua **chave de voz para texto** (o padrão é a Groq; a chave é criada em console.groq.com).
4. Em qualquer programa: segure **Ctrl + Windows**, fale e solte.

O Fala avisa quando existe versão nova e pergunta antes de baixar e antes de reiniciar.
